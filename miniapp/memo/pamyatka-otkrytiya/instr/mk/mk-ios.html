Первичная установка мобильного приложения

На iPhone «Мобильные кадры» ставятся через приложение Apple TestFlight — сначала TestFlight, потом сами «Мобильные кадры».
1. Установите TestFlight из App Store — нажмите «Загрузить».
TestFlight в App Store
2. Вернитесь на эту страницу и нажмите кнопку ниже — откроется приглашение в «Мобильные кадры». Нажмите «Продолжить», затем «Принять» и «Установить».
Установить «Мобильные кадры»
Для информации: если ссылка открылась в Safari, нажмите на странице «View in TestFlight» / «Открыть в TestFlight».
3. Откройте приложение. При первом запуске нажмите «Далее» и «Начать тестирование».
4. Теперь приложение «Мобильные кадры» есть у вас на рабочем столе.

Вход в приложение

При первом запуске приложение попросит подключить его к системе. Для этого нужен код подключения (или QR-код) — он формируется на кассе магазина.

1. Код подключения

1. Откройте приложение «Мобильные кадры».
2. Нажмите «Сканировать» и наведите камеру на QR-код — или нажмите «Ввести код подключения», введите код и нажмите «Записать».
Нет кода на кассе? Позвоните в техподдержку и попросите прислать код подключения на почту магазина или на почту руководителя команды открытия.
Позвонить в техподдержку
8-800-250-39-40

2. Номер телефона и СМС

3. Введите свой номер мобильного телефона и нажмите «Далее».
4. Прочитайте условия, включите переключатель «Подтверждаю» и нажмите «Продолжить».
5. Введите код из СМС.

3. Пин-код и вход по биометрии

6. Придумайте пин-код из 4 цифр и введите его ещё раз для подтверждения. Запомните его — он нужен при каждом входе.
7. Если на телефоне включён вход по отпечатку пальца или Face ID, приложение спросит, использовать ли его. «Да» — входить по биометрии, «Нет» — только по пин-коду.
При следующих входах приложение попросит подтвердить биометрию или ввести пин-код.
Для информации: обновления приложение предлагает само при входе. Обновить вручную: Меню → «Обновить приложение».
