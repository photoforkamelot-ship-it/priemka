Оглавление

Наше приложение доступно в RuStore

Если у Вас ещё нет RuStore, пожалуйста, установите его на www.rustore.ru

Первичная установка

1. Открыть страницу «Ярче коммуникации» в RuStore и нажать на кнопку «Скачать»
2. Дождитесь установки приложения.
3. Нажмите на кнопку "Открыть".

Прямое скачивание приложения

Если у Вас сложности с RuStore, можете получить наше приложение напрямую на сайте ya-retail.ru
1. Скачайте файл YaCom-Х.Х.Х.Х_arm64.apk на свой смартфон:
Скачать
Для старых версий Андроид попробуйте х32 версию приложения. Скачать х32
2. Загрузка файла должна начаться автоматически.
Android может показать стандартное предупреждение для неизвестных файлов. Нажмите «Все равно скачать» — файл безопасен.
3. После скачивания файла нажмите «Открыть»
Внимание! Если при запуске приложения возникнет сообщение: «Не удалось открыть файл», тогда попробуйте открыть его через «Мои файлы». В папке «Загрузки» откройте файл вида: YaCom-Х.Х.Х.Х_arm64.apk
4. Затем нажмите кнопку «Установить»

Установка приложения из неизвестного источника

5. Система может её заблокировать, если нет специального разрешения на установку приложений. Включите его в системных настройках.
5. Нажмите «Открыть». Теперь приложение «Коммуникации» есть у вас на рабочем столе

Вход в приложение

При первом входе в приложение система предложит подтвердить полномочия на работу с приложением (Рисунок 9). Необходимо ознакомиться с политикой конфиденциальности и пользовательским соглашением, перейдя по соответствующим ссылкам. Для подтверждения полномочий необходимо ответить «Подтверждаю».
Далее на устройстве необходимо ввести свой номер телефона, нажать и ввести полученный код подтверждения, который придет на данный номер телефона (Рисунок 10).
Далее для авторизации в приложении, необходимо воспользоваться одним из доступных способов: активация из письма, либо активация через кассу.

Активация приложении по письму

1. открыть электронное письмо с темой «Предоставление доступа в систему «Ярче-коммуникации»;
2. в письме найти QR-код с заголовком «Первый запуск» (самый нижний QR-код в письме);
3. если вы открыли электронную почту с мобильного устройства, где установлено приложение «Ярче коммуникации», тогда необходимо скопировать QR-код, представленный строкой, из электронного письма (Рисунок 12). Далее в мобильном приложении нажать кнопку «Ввести вручную» (Рисунок 13), вставить скопированный код в поле ввода и нажать ОК (Рисунок 14).
Если вы открыли электронную почту с другого устройства, тогда в мобильном приложении необходимо нажать кнопку «Начать сканирование» (Рисунок 15). Навести камеру мобильного устройства на QR-код, отображенный в электронном письме (Рисунок 16).

Активация приложении через кассу

1. авторизуйтесь под своим пользователем на кассе магазина (с помощью личной магнитной карты);
2. в главном меню выбрать пункт «Активировать мобильное устройство»;
3. на экране появится QR-код для сканирования (Рисунок 18); в мобильном приложении нажать кнопку «Начать сканирование» (Рисунок 19). Навести камеру мобильного устройства на QR-код, отображенный на кассе магазина.
Для загрузки установочного файла приложения, необходимо отсканировать QR-код с заголовком «Загрузка приложения».
Далее система запросит ввести пин-код. Пин-код – это короткий пароль (4 цифры), который будет использоваться при последующих входах в приложение. Необходимо придумать, ввести и запомнить пин-код, далее, ввести пин-код повторно – подтверждение пин-кода.
